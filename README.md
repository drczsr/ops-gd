# 运维工单系统（游戏服全生命周期运维平台）

> 个人作品 · 脱敏开源副本。面向大规模游戏服集群的运维平台：把分散的 SVN 配置管理、手工脚本与零散 SSH 操作，收敛成一个**有审批留痕、可回滚、可观测**的统一控制台 —— 一处管控数百台游戏服的配置、发版、合服、启停与状态。

**语言 / 技术栈**：Go · Gin · GORM · MySQL · SQLite · SSH/SCP 并发 · 腾讯云 COS · 阿里云 ALB · 企业微信群机器人 · 服务端渲染（html/template + 原生 JS）。

---

## 核心能力

- **工单流程引擎** —— 提交 → 审批 → 执行 → 测试 → 开放 五段状态机；角色门禁、审批 / 驳回、全程留痕；可审批后立即执行或定时执行。
- **服务器实例管理** —— 数百台游戏服集中视图；SSH 并发实时探测状态、启停 / 强杀 / 修复 / 内存启动、批量操作、登录限制、包版本展示。
- **游戏服配置中心** —— 配置库受管替代 SVN；表格化批量编辑、行级 diff、一键生成与发布。
- **全服配置下发工单** —— 建单冻结快照 + 线上 diff；以 COS 版本控制做基准防覆盖，审批通过后全服热下发，支持回滚到历史版本。
- **发版与全服热更** —— 换包、DB 版本逐级升级（包版本解析 + 库版本比对）、分波重试、GM 热更下发。
- **合服与合服预告** —— 合服 / 预合服工单一体化；合服预告配置库化受管。
- **创建游戏服向导** —— 自动算 ID、紧凑选机、分配端口、联动建战斗 / 中心服；事务写库、自动建库与 ALB 转发。
- **企业微信通知** —— 工单关键节点状态变化推送群机器人并 @ 责任人。
- **成员角色与权限** —— 基于角色的访问控制 + 菜单级门禁（路由 + 侧边栏双重校验）。

## 工程实践

- TDD，关键路径单测覆盖（`go test ./...`）。
- 真实执行器：系统 ssh/scp 有界并发（护住 sshd），mock / real 双模式可本地安全演练。
- 幂等与断点续跑；失败子集自动重试。
- 三重防误操作：基准校验 + 强杀拦截 + 审批门禁。
- 凭据零外泄：DB 密码只在内存连接串，不进命令、日志或前端响应。

## 目录结构

```
main.go              入口：装配依赖、注册路由、启动调度
internal/
  config/            配置加载
  handler/           HTTP 处理（Gin）
  service/
    order/           工单状态机与通知
    executor/        真实执行器：SSH、发版、合服、热更、新建/删除服、ALB
    workflow/        工单流转规则
    member/ auth/    成员、鉴权
    notify/          企业微信群机器人
  gsconfig/          游戏服配置库（含 COS 上传）
  gameserver/        服规划：发号 / 选机 / 端口分配
  mergepreview/      合服预告库管理
  configdiff/        配置行级 diff
  model/ db/ settings/
templates/           服务端渲染页面
static/              前端静态资源
scripts/             部署侧脚本（合服 / 拉配置）
```

## 本地运行

```bash
cp config.example.yaml config.yaml          # 按需修改；本地建议 executor.mode: mock
cp examples/ServerConfigList.txt ./          # 示例服列表（测试数据，GBK 编码自动识别）
go run .                                     # 默认 http://localhost:8080
```

> `examples/ServerConfigList.txt` 为示例测试数据（私网/本地 IP、占位密码），可作为 `executor.server_config_file` 指向的文件，便于本地以 mock 模式体验。
